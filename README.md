## Getting Started

### Requirements

- A C compiler such as GCC
- A code editor or IDE, such as Visual Studio Code

### Compile and run

Open a terminal in the folder containing the C source file and run:

```bash
gcc filename.c -o program
```

On Windows, run:

```bash
program.exe
```

On Linux or macOS, run:

```bash
./program
```

Replace `filename.c` with the source file you want to compile.
